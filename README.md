Karang Bay — an original top-down 2D open-world crime game: a harbor city to explore on foot and by car, with traffic, pedestrians, car stealing, wanted levels and police, 5 chained missions, HUD with minimap, save and sound. Built offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
